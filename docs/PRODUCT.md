# PRODUCT.md - Produto & Negócio

## Visão Geral do Produto

O **NERDS** (Núcleo de Estudos e Pesquisa em Desenvolvimento de Software) é um grupo de pesquisa e desenvolvimento de software da **Universidade Federal do Ceará (UFC)**. O site oficial do grupo tem como **propósito principal o recrutamento de novos membros** para as equipes de trilha.

### Objetivo Estratégico

- Atrair estudantes talentosos de graduação e pós-graduação da UFC
- Demonstrar credibility técnica através de projetos reais
- Converter visitantes em candidatos ao processo seletivo

| Atributo | Descrição |

| Atributo | Descrição |

## Jornada de Conversão

O funil de conversão do site segue a lógica: **Hero → Trilhas → Projetos → Status de Recrutamento → CTA Final**

### Etapa 1: Hero Section (Atenção)

```
┌─────────────────────────────────────────────────┐
│  ["Codifique o seu futuro na UFC"]             │
│  ["Faça parte do NERDS"]                       │
│                                                 │
│ copyprincipal.png + benefício 핵심          │
│                                                 │
│ CTA Primário: "Ver Processo Seletivo"          │
│ CTA Secundário: "Conheça Nossos Projetos"      │
└─────────────────────────────────────────────────┘
```

**Mecanismo:**
- Título grande e impactante com tom institucional + tech
- Subtítulo menciona Benefits: "projetos reais", "aprenda com os melhores", "acelere sua carreira"
- CTAs são dourados para destaque visual imediato

## Concorrentes e Diferenciais

### Concorrentes Diretos
- Labs de outras universidades (COMP, LCPD, GAESI)
- Comunidades de tecnologia locais

### Diferenciais do NERDS
1. **Foco em projetos reais** - Não só estudo, também entrega
2. **Trilhas estruturadas** - Mentoria e não só conteúdo
3. **Marca jovem e moderna** - Design "Glassmorphism" distinto do institucional tradicional
4. **Vagas limitadas** - Urgência para criar ação
